## 📊 Project Overview

This project focuses on analysing hospital-related data using Microsoft Power BI.

The dashboard provides an overview of patient demographics, hospital performance, treatment revenue, doctor performance and department-level activities.

The objective was to transform raw healthcare data into meaningful visual reports that can help users understand operational and financial performance.

## 🎯 Business Objectives

- Analyse total patients and patient demographics.
- Compare hospital-wise revenue and performance.
- Understand treatment and department-level revenue.
- Evaluate doctor performance and treatment activity.
- Monitor financial KPIs.
- Present findings through interactive dashboard pages.

## 🛠️ Tools and Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel | Source dataset |
| Power BI | Dashboard development |
| Power Query | Data cleaning and transformation |
| DAX | KPI calculations and measures |
| Data Visualization | Business reporting and insights |

## 🧹 Data Preparation

The following data preparation activities were performed using Power Query:

- Checked and handled duplicate patient records.
- Checked missing values.
- Corrected data types.
- Cleaned hospital names.
- Standardized department names.
- Extracted year, month and quarter information.
- Created patient age groups.

## ⚠️ Data Limitations

The source dataset did not contain an occupied-beds field. Therefore, bed utilization could not be accurately calculated.

This highlights the importance of checking data availability before defining business KPIs.
